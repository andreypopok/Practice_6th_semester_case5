Кейс-задача № 5. Генерация HTML-страницы организации
ЗАО «Международный деловой альянс»

Один файл generate.py создаёт шесть HTML-страниц с одинаковыми сведениями
об организации и разными шрифтами. CSS включён в каждую страницу.

ЗАПУСК

Откройте терминал в папке проекта и выполните:

    python generate.py

Затем откройте output/index.html в браузере.
